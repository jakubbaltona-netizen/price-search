# Wyszukiwarka cen Cabin Store

Gotowy pakiet do publikacji w GitHub Pages.

## Pliki
- `index.html` – wyszukiwarka
- `prices.json` – 202 produktów i ceny sprzedaży

## Publikacja
1. Utwórz nowe repozytorium na GitHubie, np. `price-search`.
2. Wgraj do głównego katalogu repozytorium pliki `index.html` i `prices.json`.
3. Wejdź w **Settings → Pages**.
4. W **Build and deployment** wybierz **Deploy from a branch**.
5. Wybierz **main** oraz folder **/(root)** i kliknij **Save**.
6. Po 1–3 minutach strona będzie dostępna pod adresem wyświetlonym w GitHub Pages.

## Aktualizacja cen
Po przygotowaniu nowej wersji `prices.json` zastąp stary plik w repozytorium. Kod strony nie wymaga zmian.

Uwaga: repozytorium publiczne oznacza, że dane z `prices.json` są publicznie dostępne. Do cennika firmowego użyj prywatnego repozytorium z innym hostingiem lub rozwiązania z logowaniem.
